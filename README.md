WorkLance – Freelance Marketplace Platform
📌 Overview
WorkLance is a modern freelance marketplace web application that connects clients and freelancers on a single platform. Clients can post projects, hire freelancers, manage contracts, and process payments, while freelancers can browse projects, submit proposals, complete work, and receive payments securely.

The platform also includes an Admin Panel for managing users, projects, disputes, payments, and overall system activities.

⚙️ Installation & Setup
1️⃣ Clone Repository
git clone (https://github.com/simarjeetdua/WorkLance-AI-Powered-jobHunt.git)

2️⃣ Navigate to Project Folder
cd worklance

3️⃣ Install Dependencies
Frontend
cd frontend
npm install
Backend
cd backend
npm install

4️⃣ Environment Variables
Create a .env file in backend folder:

PORT=5000

DB_HOST=
DB_USER=
DB_PASSWORD=
DB_NAME=

JWT_SECRET=

CASHFREE_APP_ID=
CASHFREE_SECRET_KEY=

5️⃣ Run Application
Start Backend
npm run server
Start Frontend
npm start
